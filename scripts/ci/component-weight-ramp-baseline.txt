# scripts/ci/component-weight-ramp-baseline.txt
#
# The known-open violations of scripts/ci/component-weight-ramp-gate.sh, one
# per line, as `path::selector::property::value`.
#
# This is a RATCHET, not an allowlist. It records what is already broken so the
# gate can land green and still fail the PR that introduces the NEXT violation.
# An entry is deleted in the same PR that fixes the violation; the gate errors
# if an entry stops matching anything, so this file cannot quietly become a
# graveyard. Widening it to make a new violation pass is the thing it exists to
# prevent — a legitimate new weight goes into DESIGN.md's `typography:` first,
# which is design-lead's call, not this file's.
#
# THIS FILE IS CURRENTLY EMPTY, and that is the intended end state rather than
# a gap. STI-516 landed the gate with all six violations recorded here as
# baseline entries; STI-515 then fixed all six and deleted all six entries in
# the same PR, which is exactly the ratchet discipline this file asks for. The
# ratchet did its job: the gate was red on the STI-515 branch until this file
# was tightened, and green afterwards. A future `font-weight: 600` in
# component CSS is now an ordinary gate failure with no baseline to hide in.
#
# Do not re-add a violation here to get a PR to green. Fix the selector.
#
# SCOPE, stated honestly so nobody assumes coverage that does not exist. This
# gate is TIER 1 of the three STI-516 describes, and it is the only tier that
# ships. It is green iff the weight ramp is respected.
#
#   Tier 1 (SHIPPED HERE) — a literal `font-weight` / weight-leading `font:`
#                         shorthand outside DESIGN.md's `typography:` ramp.
#   Tier 2 (DEFERRED)    — raw literals on the 4px grid or the type steps,
#                         e.g. `font-size: 0.7rem`, or a raw `padding: 12px`
#                         where a `--space-*` step exists. Needs an allowlist
#                         for genuinely one-off values, or it produces false
#                         positives. STI-515 fixed the one instance it named
#                         (`.cart-pill__count`), but the tier still ships.
#   Tier 3 (DEFERRED)    — selector -> `components:` token diffing. Would have
#                         caught STI-486's F1 and F3, a `transparent` background
#                         where `components.input.backgroundColor` declares
#                         charcoal. Needs a hand-maintained mapping file.
#
# Also NOT covered, deliberately: `font-weight="600"` as an SVG presentation
# attribute on a <text> element. That is markup, not a CSS declaration. The
# gate prints those as an ADVISORY on every run so they stay visible; both
# that STI-516 found (Header.vue, index.vue) were fixed by STI-515, so no
# advisory is expected until the next one is introduced.
# `bolder` / `lighter` are relative weights and cannot be checked against a
# closed set, so they are not checked.
